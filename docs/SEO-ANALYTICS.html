Which tool answers which question

The single most important distinction in this effort — conflating these two wastes a lot of time.

QuestionToolWhy
What did people type into Google before clicking?Search ConsoleGoogle's own server-side query log. Exact, free.
What did they do once they arrived?Google Analytics 4On-site behavior: pages, clicks, funnel completion.
What terms could I rank for, and how hard?Ahrefs freeEstimated from Ahrefs' own SERP crawl — not real visitors.
GA4 structurally cannot report search queries. Google stripped query terms out of the HTTP referrer in 2011 (the "(not provided)" change) and finished the job in 2013. No amount of instrumentation recovers this, because the data never reaches the page. This is not a configuration gap.

The account ID in the picker is the only reliable way to tell them apart. Granting on 18083060 appears to succeed and then reports nothing, because it has no properties.

Removing the last administrator locks you out. Granting the service account Administrator at the account level and then deleting the only human administrator removed all human access to 18083060. Recovery worked only because the service account itself held admin and could re-grant access through the API. Two rules follow: grant the service account Viewer on the property, never Administrator on the account; and keep at least two administrators on any GA account that matters.

Recovery procedure — note accessBindings is v1alpha, not v1beta:

TOKEN=$(gcloud auth print-access-token \
  --impersonate-service-account=seo-reporting@samkirk-v3.iam.gserviceaccount.com \
  --scopes=https://www.googleapis.com/auth/analytics.manage.users)

curl -s -X POST -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"user":"sam@samkirk.com","roles":["predefinedRoles/admin"]}' \
  https://analyticsadmin.googleapis.com/v1alpha/accounts/<ACCOUNT_ID>/accessBindings

What is actually rankable

The blocking defect: real content sits inside an iframe

StaticHtmlViewer renders each exploration's substance in an iframe from /static/*.html. Google does not credit iframe content to the parent page, so what actually ranks is only the wrapper copy.

Every one read to Google as a thin stub — the content already existed and was genuinely distinctive, it was simply invisible to the crawler.

FIXED 2026-07-29 — content is now server-rendered

StaticHtmlContent (a server component) replaces StaticHtmlViewer on all eight affected pages. The document is read from public/static at build time and inlined, so the markup ships in the initial HTML. Each document's own stylesheet is rewritten by lib/static-html.ts so every selector is confined to a wrapper class — without that, its bare body, *, and h1 rules would restyle the whole site.

All eight /static/*.html files now also carry <link rel="canonical"> pointing at their parent page, so the standalone copies no longer compete with the pages that embed them.

Compounding it, the /static/*.html files are crawlable (robots.txt only disallows /admin/ and /api/), carry their own <title>, have no meta description and no canonical, and are absent from the sitemap. They are orphan pages that can be indexed in competition with their own parent, splitting whatever signal exists.

On Ahrefs free

Ahrefs Webmaster Tools (free tier) gives verified site owners Site Explorer limited to 1K keywords/backlinks visible at once, Site Audit with 5K crawl credits per month, and Web Analytics. Own sites only — no competitor lookups.

It reports keywords the site ranks for, derived from Ahrefs' own crawl of Google's results plus clickstream modelling, with search volume and keyword difficulty attached. That is an estimate about the search results page, not a record of actual visitors — so it does not answer "what were users searching when they clicked my site". Search Console does, exactly and for free.

Recommendation: yes, create the free account. Search Console only reports terms already earning impressions — it is structurally blind to terms the site does not yet rank for, and it reports neither search volume nor difficulty. Ahrefs Webmaster Tools supplies estimated volume and keyword difficulty alongside the rankings, which is exactly what is needed to choose which candidate topic to invest in.

Setup cost is genuinely small. Verification can be done by connecting the existing Google Search Console property rather than adding DNS records or uploading files — a few minutes, and the GSC side is already verified. No payment method is required for the free tier.

What it will and will not answer. It reports volume and difficulty for queries the site already ranks for — useful for deciding whether the striking-distance terms are worth chasing. It is weaker for terms with no ranking at all; for those, Ahrefs' standalone free Keyword Difficulty Checker and Keyword Generator accept arbitrary terms without an account, which covers the "should I write about LoRA fine-tuning on Apple Silicon?" question.

Treat every number as an estimate. Ahrefs positions and traffic figures come from its own index and clickstream modelling. Where the two disagree, Search Console is ground truth — it is Google's own log. Use Ahrefs for relative comparison between candidate terms, not for absolute traffic forecasts.
