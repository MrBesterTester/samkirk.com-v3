# Codex Project Guidance

This repository's shared project guidance remains in `CLAUDE.md` so Claude and Codex use one source of truth.

## Required startup

- Before substantive work, read `CLAUDE.md` completely and apply its relevant project instructions.
- Treat current system and developer instructions, followed by this `AGENTS.md`, as higher priority if guidance conflicts.

## Codex compatibility

- Translate Claude-specific tool or command names to the equivalent currently available Codex skill or tool.
- Do not assume a Claude-only capability exists; verify the corresponding Codex capability before using it.

## Shared-file protection

- Do not modify `CLAUDE.md` unless Sam explicitly requests it.
